Context Cache Timeline

Incubating feature: this timeline is new and still evolving. Feedback is very welcome - please let us know what you think.

Each bar is one lifetime of a Spring ApplicationContext in the TestContext cache: the dark segment is the context load (leading up to the moment it entered the cache), the light segment is the time it stayed cached. A bar ends when the context was removed from the cache (@DirtiesContext or LRU eviction) - or runs dashed to the end of the test run if it stayed cached.
